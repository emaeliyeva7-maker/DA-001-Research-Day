## Part 1: Data Analytics Nədir?
Data analitika məlumatların toplanması, təmizlənməsi, araşdırılması və təhlil edilməsi prosesidir. Bu proses şirkətlərə daha düzgün qərarlar qəbul etməyə, müştərilərini daha yaxşı tanımağa, xrclərini azaltmağa və resurslardan daha sərfəli istifadə etməyə kömək edir.

### 1.2 Data Analitikanın Əhəmiyyəti

### 1.3 Analitikanın 4 Növü
Data analitika məqsəd və istifadəsinə görə 4əsas qrupa bölünür. Bu növlər şirkət və bizneslərə keçmiş hadisələri anlamağa, problemlərin səbəblərini tapmağa, gələcəyi proqnozlaşdırmağa  və düzgün qərarlar qəbul etməyə kömək edir. Növlər: Descriptive, Diagnostik, Predictive, Prescriptive Bu növlərin hər birir bir biri ilə əlaqəlidir.

### 1.4 Data Analyst vs Data Scientist
Data Analyst və Data Scientist məlumatlarla işləyən iki fərqli peşədir. Hər ikisinin əsas məqsədi məlumatlardan faydalı nəticələr əldə etməkdir. Data analyst: Mövcud məlumatları toplayır və analiz edir, məlumatların təhlili ilə problemləri həll etməyə kömək edir, Excel,SQL,Power BI kimi alətlərdən istifadə edir, Hesabatlar və Dashboardlar hazırlayır. Data scientist: Böyük və mürəkkəb məlumatlarla işləyir, Statistik metodlardan istifadə edir, gələcəyi proqnozlaşdırmaq üçün modellər hazırlayır, Python kimi proqramlaşdırma dillərindən istifadə edirş bu iki anlayış arasında əsas fərq: Data analystmövcud məlumatlardan istifadə edərək nəticələri izah edir, Data scientist isə daha mürəkkəb modellər hazırlayaraq gələcəyi proqnozlaşdırırş Bununla belə bu iki proses bir şirkətdə üst-üstə düşə bilər

### 1.5 Real-World Company Examples
Data analitika şirkətlərin fəaliyyətində mühüm rol oynayır. Bir çox beynəlxalq şirkətlər gündəlik qərarlarını buna əsasən qəbul edir. Amazon: müştərilərin alış-veriş tarixçələrini, axtarışlarını, məhsul seçimlərini analiz edir. Buna əsasən fərdi təkliflər hazırlayır, anbar ehtiyatlarını tənzimləyir. Netflix: müştərilərin izlədikləri, bəyəndikləri və daha çox axtardıqları filmlərin siyahısını və s. məlumatları toplayıb. təhlil edir. Ona uyğun filmlər təklif edir. Bu nümunələr göstərir kiç data analitika yanlızca rəqəmlər deyil. Şirkətlərə özlərini inkişaf etdirməyə imkan verir. 

## Part 2: Data Analytics Tools
### 2.1 Excel
Excel Data Analytika sahəsində ən çox istifadə olunan alətlərdən biridir. Excel məlumatların təhlilində, vizuallaşdırılmasında və məlumatların cədvəl formatında saxlanılmasında faydalıdır. Əsas sahələr: məlumatların cədvəldə saxlanılması, riyazi və statistik hesablamaların aparılması, Formula və funksiyalardan istifadə olunması, Pivot Table vasitəsilə məlumatların ötürülməsi və s. Nə zaman istifadə edərəm? Kiçik və orta həcmli məlumatları təhlil etmək, hesablamalar aparmaq və hesabatlar hazırlamaq üçün Excel seçərəm
### 2.2 SQL
SQL Database ilə ilə işləmək üçün istifadə olunana sorğu dilidir. Onun vasitəsilə məlumatları seçmək, əlavə etmək , silmək mümkündür. Şirkətlər məlumatları Database'də saxlayır. SQL bu məlumatlar arasında lazım olanı seçməyə və təhlil etməyə imkan verir. Əsas istifadə sahələri: Database dən məlumat götürülməsi, müəyyən şərtlərlə məlumatları seçməyi, məlumatları qruplaşdırılması və cədvəllər arasında əlaqə qurulması və s.
### 2.3 Python
Python fərqli məqsədlərə çatmaq üçün istifadə olunan proqramlaşdırma dilidir. Data analitika sahəsində geniş yayılıb çünki təhlil, vizuallaşdırma və s. prosesləri asanlaşdırır. Pythonın əsas üstünlükləri çox saylı kitablarının olmasıdır.
### 2.4 Power BI
Power BI Microsoft tərəfindən hazırlanmış məlumatların təhlili və vizuallaşdırılması proqramıdır. Bu alət mənbələrdən məlumatlar toplayaraq məlumatları birləşdirib vizuallaşdırmağa , dashboardlar hazırlamağa imkan verir.

## Part 3: Data Analytics Workflow
Data Analyst-in gündəlik işi şirkətin ehtiyaclarından və layihənin məqsədindən asılı olaraq dəyişir. Lakin əsas fəaliyyətlər məlumatların əldə edilməsi, təmizlənməsi, təhlili və nəticələrin təqdim edilməsindən ibarətdir. Data Analyst yalnız kompüterdə məlumatlarla işləmir. O, həmçinin şirkətin qarşılaşdığı problemləri öyrənir, rəhbərliklə və digər komandalarla əməkdaşlıq edir və analiz nəticələrini izah edir.
### 3.1. Data colletting
Məlumatlar müxtəlif mənbələrdən toplanır. Bir yerdə yığılır. İstifadə edilən proqramlar : Excel , SQL
### 3.2 Data Cleaning
Toplanan məlumatlar təhlil üçün hazırlanır. Səhvlər ç anlaşılmazlıqlar və qanuna uyğunsuzluqlar aradan qaldırılır. İstifadə olunan proqramlar: Excel, Python
### 3.3 Data Analysis
Əldə olunan məlumatlar məqsədə uyğun təhlil olunur, hesablamalar aparılır və hesabatlar hazırlanır.İstifadə olunan proqramlar: Excel, SQL, Python
### 3.4 Data Visualization
Hesabatlara və təhlilə uyğun qrafiklər, diaqramlar vəə s. qurulur.İstifadə olunan proqramlar: Excel, Power BI,Python
### 3.5 Data Reporting
Bu mərhələdə bütün hesabatlar ümumiləşdirilir və şirkətə təqdim olunur. Gələcək qərarların alınması üçün istifadə olunur.
